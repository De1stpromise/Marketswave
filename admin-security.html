Changing your password re-verifies the current one first — Supabase’s own update call trusts your existing session and has no current-password step of its own, so without that check the field above would be decorative.

Enter a password

This signs you out everywhere else. Every other session is ended and its refresh token revoked, so no other device can sign itself back in without the new password. This device stays signed in. A device that was already loaded keeps working for up to an hour, until the access token it is holding expires — to cut one off now, end its session below.
